# tma-starter

Building blocks for Telegram Mini Apps: a NestJS backend with Telegram auth, users, admin rights, a grammY bot and Telegram Stars payments, a React client, and test utilities. The fastest way to start is the [tma-starter Claude Code plugin](https://github.com/dmytro-rudenko/tma-starter), which generates a full app on top of this package.

## Install

```
pnpm add tma-starter
```

All peer dependencies are optional. Install the ones for the subpaths you import:

| Subpath | Peer dependencies |
| --- | --- |
| `tma-starter/nest-core` | `@nestjs/common`, `@nestjs/core`, `@nestjs/throttler`, `@nestjs/websockets`, `@nestjs/platform-socket.io`, `socket.io`, `knex`, `pg`, `class-validator`, `class-transformer`, `reflect-metadata`, `rxjs` |
| `tma-starter/nest-bot` | `nest-core` peers and `grammy` |
| `tma-starter/nest-payments` | `nest-core` peers and `grammy` |
| `tma-starter/web`, `tma-starter/web/react` | `react`, `@tanstack/react-query`, `i18next`, `react-i18next`, `socket.io-client` |
| `tma-starter/testing`, `tma-starter/testing/dom` | `@nestjs/testing`, `supertest`, `knex`, `pg` |

Server subpaths are CommonJS, web subpaths are ESM; every subpath ships type declarations.

## Server

```ts
import { Module } from '@nestjs/common';
import { TmaCoreModule } from 'tma-starter/nest-core';
import { TmaBotModule } from 'tma-starter/nest-bot';
import { TmaPaymentsModule, type Product } from 'tma-starter/nest-payments';

const products: Product[] = [
  {
    id: 'premium',
    kind: 'subscription',
    priceStars: () => 250,
    title: (lang) => ({ uk: 'Преміум', en: 'Premium' })[lang],
    description: (lang) => ({ uk: 'Преміум на 30 днів', en: 'Premium for 30 days' })[lang],
  },
];

@Module({
  imports: [
    TmaCoreModule.forRoot({ knex, botToken, adminUserIds: [123456789] }),
    TmaBotModule.forRoot({ botToken, botUsername, webappUrl, webhookPathToken, webhookSecret }),
    TmaPaymentsModule.forRoot({ products }),
  ],
})
export class AppModule {}
```

- `nest-core`: verifies Telegram `initData`, stores users, manages admin rights, `app_settings` and the audit log, and runs the realtime gateway.
- `nest-bot`: the bot webhook, notifications, broadcasts with a worker lease, and the `tma-bot` CLI.
- `nest-payments`: Telegram Stars invoices, one-time purchases and subscriptions, refunds, entitlements, admin endpoints and reconcile.

Each server subpath exports `migrations`. Combine them with your own through `composeMigrations` from `tma-starter/nest-core` and run them with knex.

## Web

```tsx
import { tg } from 'tma-starter/web';
import { TmaProvider, createQueryClient, useMe } from 'tma-starter/web/react';
```

`tg` wraps `window.Telegram.WebApp`; the package also provides an API client that sends `initData`, i18n setup, and React hooks for the current user, purchases and realtime events.

## Testing

`tma-starter/testing` signs test `initData` (`signInitData`, `tmaAuth`), starts a fake Telegram Bot API (`startFakeBotApi`), builds a Nest app (`createTestApp`), and gives each test a fresh database cloned from a migrated template (`createTestDatabase`). The `tma-test-pg` CLI starts a local PostgreSQL 16 for tests. `tma-starter/testing/dom` provides `installFakeWebApp` for jsdom.

## Upgrading

```
pnpm up -r tma-starter@latest
pnpm db:migrate
```

In a project generated by the plugin, `pnpm db:migrate` applies the migrations a new version may add; run it after every upgrade.
